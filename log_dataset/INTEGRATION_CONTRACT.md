# Data and model integration contract

The corpus entry point is `python build_dataset.py`. Its independent
[cache stages](CACHE.md) import enriched archives, replay decisions, compute
structural analysis, scoring, eligible yaku, participation and observed labels,
then apply AFK and focused sampling. The normalized SQLite cache uses integer
parent keys and separate tensor components. `log_dataset.materialize` streams
those components into compressed TFRecords without replay or feature encoding.
Critic computation remains on the on-the-fly path.

The integration scenario checks direct/cached tensor and TFRecord equivalence,
TensorFlow training-parser equivalence, participation values, foreign keys,
indexed export without a temporary sort,
and stage invalidation followed by re-export with the archives removed.

`train.py` runs the fixed training and evaluation sequence from a validated
TFRecord summary and writes a reloadable
Keras model and SavedModel. Export, frozen-policy inference, duplicate-game
evaluation and serving must continue to consume the same feature and action
contracts. The existing model preservation contract remains authoritative for
architecture, objectives, labels, native search and runtime requirements.

The rewritten suite must cover these workflows through public entry points:

- enriched archive → TFRecord and SQLite rows, including AFK removal and a
  structural discard summary;
- TFRecord → one fixed-recipe experiment update → reloadable SavedModel;
- replay and serving agreement for legal discard/call/win decisions;
- duplicate evaluation rotation, fixed queues, honba and dealer-renchan payment;
- consequential malformed/archive-contract failures.

Controller capture, browser, player-tracking and service transport tests are
outside this rewrite boundary. Generated bytecode and stale solver-test
bytecode are artifacts, not test inputs. Baseline commands are the retained
integration scenarios, `python build_dataset.py --help` and
`python train.py --help`; measured model
quality and full training throughput remain unverified by a smoke suite.
